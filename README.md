## 🏗️ 项目架构
### 核心技术栈
- **主控芯片**：STM32F407
- **通信总线**：CAN 总线
- **实时系统**：FreeRTOS（任务调度、互斥锁、队列）
- **通信协议**：自定义红外模块通信协议（含 CRC8 校验）
- **关键算法**：CRC8（多项式 0x07）、超时重传机制

### 核心流程
1.  **CAN 接收链路**：CAN 中断 → 帧处理 `ProcessRxFrame` → 消息入队 → 任务处理 `Handle`
2.  **命令发送链路**：忙状态检查 → 帧间隔等待 → CRC 计算 → CAN 发送 → 状态更新
3.  **状态管理**：3 秒超时离线检测、在线/忙状态实时维护
